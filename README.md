# EvercodeLab Selection Task

## Запуск проекта

npm start

## Структура проекта

- modules/config.js - настройки приложения
- modules/logger.js - модуль логирования
- scheduler.js - управление периодическими задачами
- index.js - точка входа

## Что делает проект

При запуске создаётся периодическая задача task1, которая каждые 10 секунд выводит сообщение running через логгер.
